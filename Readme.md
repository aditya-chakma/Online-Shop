# Therap Shop

## Introduction

In our e-commerce app there are two kinds of user roles:

* Admin
* Customer.

An Admin can add, update, add discount and discontinue products in the existing inventory. An admin can also confirm or reject an incoming order. Admin has the ability to view existing inventory. Inventory has multiple categories and a single product belongs to a unique category. A customer can view all products without any login credentials. Customers have to be registered only for order related issues. Registered customers can view his/her previous orders history. He/She also can add products to carts. Admin and Customer can search any product by name.

## Features

### Admin

* Login
* Add Product
* Discontinue Product
* Update Product
* See all Products
* Confirm Order
* Reject Order
* Search Product by name

### Customer

* Register
* See all Products
* Add Product to Cart
* Checkout Cart
* Place Order
* Delete Order
* View previous Order history
* Search product by name
